# Mechanics progression

Start with [Tier 0](../fundamentals/tier-0/README.md), then work through the tiers
in the order below. Each folder has a complete lesson, a runnable `main.py`, and
an editable `cases/baseline.json`.

| Tier | Focus |
|---|---|
| [1](tier-1/README.md) | Axial stress, strain, and temperature |
| [2](tier-2/README.md) | Circular torsion, pin shear, plate bearing |
| [3](tier-3/README.md) | Bending stress and beam deflection |
| [4](tier-4/README.md) | Combined loading and stress transformation |
| [5](tier-5/README.md) | Compatibility, thermal mismatch, energy |
| [6](tier-6/README.md) | Elastic column buckling |
| [7](tier-7/README.md) | Stress concentration, fatigue, fracture |
| [8](tier-8/README.md) | Assembled 1D FEA and mesh convergence |

Run all baseline cases with `python3 run_all.py` from the repository root.
“Advanced” is the common progression folder name; the early tiers still begin
with fundamental mechanics. All tiers share the [same equation style](../docs/equation-style.md).
